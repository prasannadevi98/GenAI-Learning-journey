# GenAI Learning Journey

This repository documents my step-by-step learning journey with TechPanda. I am learning Python from the basics to advanced concepts, then applying it to Generative AI and agentic AI.

## What I Have Done

### Day 1: Python Basics

The notebook [Python_Day1_Basics_Practice.ipynb](Python_Day1_Basics_Practice.ipynb) contains explanations, examples, and practice tasks for:

- Single-line comments and multi-line text
- Python keywords and case sensitivity
- Variables and variable naming rules
- Multiple assignment
- Core data types: `int`, `float`, `complex`, `str`, and `bool`
- Checking values with `type()`
- Displaying values with `print()`
- Escape sequences such as `\\`, `\n`, and `\t`
- Multi-line strings and formatted output
- A mini exercise combining the Day 1 concepts

## What I Am Going To Learn

I will continue learning step by step in this order:

1. Python fundamentals: operators, conditions, loops, functions, collections, and modules
2. Practical Python: file handling, exceptions, object-oriented programming, testing, and Git
3. Advanced Python: iterators, generators, decorators, context managers, typing, and APIs
4. Data and automation: NumPy, Pandas, databases, web development, and automation projects
5. Generative AI: prompt engineering, embeddings, vector databases, RAG, and LLM applications
6. Agentic AI: tool use, workflows, memory, planning, multi-agent systems, and reliable AI agents
7. Projects: build, document, test, and share projects that combine Python, GenAI, and agentic AI
